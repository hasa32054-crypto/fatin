# تشغيل خادم فطن (مجاني بالكامل، 10 دقائق)

الخادم يخلي كل ميزات فطن تشتغل لأي أحد يفتح التطبيق من GitHub:
الذكاء الاصطناعي (تحليل الرسائل والصور، «اسأل فطن»، المحتال في التدريب)، ولوحة الأسرة، ورادار البلاغات.

**ما يحتاج مفتاح Claude، ولا بطاقة بنكية.** الذكاء الاصطناعي يجي من Cloudflare نفسها (Workers AI) مجانًا.

## اللي تحتاجه
- حساب Cloudflare مجاني من dash.cloudflare.com (إيميل وكلمة مرور بس).

## الخطوات من المتصفح (بدون أوامر)
1. في Cloudflare: **Workers & Pages ← Create ← Create Worker**، سمّه `fatin`، واضغط **Deploy**.
2. اضغط **Edit code**، احذف الكود الموجود، والصق محتوى ملف `worker.js` كامل، ثم **Deploy**.
3. من القائمة الجانبية: **Storage & Databases ← KV ← Create**، وسمّها `fatin-data`.
4. ارجع للـWorker: **Settings ← Bindings ← Add**:
   - اختر **Workers AI**، والاسم `AI`.
   - مرة ثانية **Add ← KV namespace**، الاسم `FATIN_KV`، واختر `fatin-data`.
5. انسخ رابط الـWorker، مثل `https://fatin.اسمك.workers.dev`. لو فتحته في المتصفح يطلع لك `{"service":"fatin","ok":true}`.
6. في GitHub افتح `app/config.json` واضغط القلم ✏️، وحط الرابط:
   ```json
   { "server": "https://fatin.اسمك.workers.dev" }
   ```
   ثم **Commit changes**. بعد دقيقة تشتغل كل الميزات في التطبيق لكل الناس.

## الحد المجاني
- Cloudflare تعطي حصة مجانية يومية، تكفي تقريبًا 250 إلى 300 طلب ذكاء اصطناعي في اليوم، وتتجدد كل يوم.
- لو خلصت الحصة، التطبيق ما يتعطل: يرجع للفحص على الجهاز (يشتغل بدون إنترنت)، والمحتال في التدريب يرد بنصوص جاهزة.
- ما يحتاج تحدد حد يومي للنموذج المجاني، لأن Cloudflare توقفه لحالها لما تخلص الحصة، وما يكلفك ولا ريال.

## اختياري: استخدام Claude بدل النموذج المجاني
النموذج المجاني جيد، لكن عربيته أضعف شوي من Claude. لو حاب تستخدم Claude:
**Settings ← Variables and Secrets ← Add**، النوع **Secret**، الاسم `ANTHROPIC_API_KEY`، والقيمة مفتاحك من console.anthropic.com (يحتاج بطاقة، والدفع حسب الاستخدام).
ومع Claude يشتغل حد يومي يحمي حسابك: 400 طلب، وتقدر تغيّره بمتغير اسمه `DAILY_CAP`.
لو حذفت المفتاح، يرجع للنموذج المجاني تلقائيًا.

## الحماية الموجودة
- الخادم يقبل طلبات الذكاء الاصطناعي من موقعك على GitHub فقط.
- حد يومي: حصة Cloudflare المجانية للنموذج المجاني، أو 400 طلب مع مفتاح Claude.
- لوحة الأسرة تحفظ نوع التنبيه والوقت والاسم الأول فقط، وتنحذف بعد 14 يوم.
- الرادار يحفظ نوع النمط فقط، بدون نص أي رسالة.

## للمبرمجين (wrangler)
عدّل `id` في `wrangler.toml` إلى رقم الـKV حقك، ثم `npx wrangler deploy`.

## الصوت الذكي (اختياري)

بدونه فطن يستخدم صوت الجوال. معه، المتصل يتكلم بصوت **حامد** السعودي وفطن بصوت **زارية**، من Microsoft Azure، وكل اللغات العشر لها صوت طبيعي.

1. سوّ حساب في portal.azure.com (يطلب بطاقة للتحقق، والطبقة المجانية F0 فيها ٥٠٠ ألف حرف بالشهر).
2. Create a resource → ابحث عن **Speech** → Create.
3. Pricing tier: **Free F0**، Region: **East US**.
4. بعد ما يخلص: Keys and Endpoint → انسخ **KEY 1** و**Location/Region**.
5. في Cloudflare: الـWorker → Settings → Variables and Secrets:
   - `AZURE_TTS_KEY` (Secret) = KEY 1
   - `AZURE_TTS_REGION` = المنطقة، مثل `eastus`

الجمل المتكررة تنحفظ ٣٠ يوم في FATIN_KV. لو صار أي خطأ، التطبيق يرجع لصوت الجوال تلقائيًا. (ElevenLabs بديل: `ELEVENLABS_API_KEY`.)
