# واجهة فطن المفتوحة (API) وحزمة المطورين (SDK)

> للجهات الحكومية والبنوك وشركات الاتصالات والمطورين. المواصفة الكاملة: [`openapi.yaml`](openapi.yaml) (OpenAPI 3.1).
> **فطن مشروع طالب مستقل، وليس تابعًا لأي جهة حكومية أو بنك.** الربط الرسمي بإذن كتابي من المالك.

## ثلاث طرق للربط

| الطريقة | لمن | البيانات |
|---|---|---|
| **1. حزمة SDK داخل التطبيق** `sdk/fatin-engine.js` | تطبيقات تبي الفحص داخل الجوال بدون إنترنت (أعلى خصوصية) | ما يطلع أي شي من الجهاز |
| **2. الواجهة المفتوحة** `/v1/...` | أنظمة الخوادم، بوتات الواتساب، مراكز الاتصال | النص يُفحص ولا يُحفظ |
| **3. التطبيق المصغّر** `app/?embed=1` | التطبيقات الشاملة (توكلنا وغيره) — انظر [`integration.md`](integration.md) | حسب موافقة المستخدم |

## 1) حزمة SDK (بدون إنترنت)

```html
<script src="https://hasa32054-crypto.github.io/fatin/sdk/fatin-engine.js"></script>
<script>
  const r = Fatin.check("أبشر: حدّث بياناتك عبر absher-update.click");
  // r.verdict → "danger" · r.score → 0-100 · r.reasons → ["…"] · r.signals → ["update","lookalike"]
</script>
```
```js
// Node.js
const Fatin = require("./fatin-engine.js");
Fatin.check("Your package is on hold, pay 1.99 at usps-redeliver.xyz").verdict; // "danger"
```
الحزمة تُبنى آليًا من محرك التطبيق نفسه (`node tools/build-sdk.mjs`)، فالنتيجة واحدة في التطبيق والخادم والحزمة. الحجم ~68KB.

## 2) الواجهة المفتوحة

العنوان الحالي: `https://fatin.hasa32054.workers.dev` (وبعد النقل: خادم داخل المملكة).

### فحص رسالة
```bash
curl -X POST https://fatin.hasa32054.workers.dev/v1/check \
  -H "content-type: application/json" \
  -d '{"text":"البنك: حسابك موقوف، أرسل رمز التحقق اللي وصلك"}'
```
```json
{"verdict":"danger","score":60,"reasons":["يطلب منك رمز التحقق. الجهات الرسمية ما تطلبه منك أبدًا."],"signals":["otp"],"links":[],"brands":["البنك"],"lookalike":null,"engine":"1.0.…"}
```

### فحص رابط (يفتحه الخادم بأمان)
```bash
curl -X POST …/v1/link -H "content-type: application/json" -d '{"url":"https://bit.ly/xxxx"}'
```
يرجّع: وين يوصل فعلًا، سلسلة التحويلات، هل الموقع رسمي، هل يطلب بطاقة أو رمز أو كلمة مرور، عمر النطاق، والنتيجة.

### نطاقات الاحتيال (للجهات ومراكز الاستجابة)
- `GET /v1/feed` — JSON: النطاقات اللي حكم عليها قارئ الروابط بـ«خطر» آخر 30 يوم.
- `GET /v1/feed.stix` — نفس القائمة بصيغة **STIX 2.1** المعيارية لتبادل معلومات التهديدات (تُستورد في منصات مثل MISP وOpenCTI).
- يُحفظ **النطاق فقط** (مثل `smsa-track.top`) — بدون الرابط الكامل وبدون أي معلومة عن المستخدم. المنصات المشتركة (Google Docs، GitHub Pages، الروابط المختصرة…) ما تُضاف لأن النطاق نفسه مو خطير.
- آلي وغير مُراجَع من أي جهة — يُستخدم كمؤشر، لا كقرار حجب.

### إحصاءات الرادار
`GET /v1/stats` — عدد البلاغات حسب نوع الاحتيال آخر 7 أيام. أرقام مجمّعة فقط.

## الحدود والمفاتيح

| الخدمة | بدون مفتاح | مع مفتاح شريك |
|---|---|---|
| `/v1/check` | 60 / 10 دقائق لكل IP | ×50 |
| `/v1/link` | 20 / 10 دقائق | ×50 |
| `/v1/feed` و `/v1/stats` | 30–60 / 10 دقائق (ومخزنة 5 دقائق) | ×50 |

**مفتاح الشريك:** يرسَل في `Authorization: Bearer <key>`. الخادم يحفظ **بصمة SHA-256** للمفتاح فقط في `PARTNER_KEY_HASHES` (ما يُحفظ المفتاح نفسه). لإصدار مفتاح لجهة:
```bash
node -e "const k=require('crypto').randomBytes(24).toString('base64url'); console.log('المفتاح (للجهة فقط):',k); console.log('البصمة (للخادم):',require('crypto').createHash('sha256').update(k).digest('hex'))"
```
تعطي الجهة المفتاح بقناة آمنة، وتحط البصمة في Cloudflare ← Settings ← Variables (أكثر من جهة: افصل البصمات بفاصلة).

## الخصوصية والأمان
- `/v1/check` ما يحفظ ولا يسجّل النص. السجلات: الوقت والمسار والحالة فقط.
- بدون كوكيز، CORS مفتوح (`*`) لأن ما فيه بيانات جلسة، وكل الخدمات بحد طلبات.
- حماية SSRF في قارئ الروابط (عناوين داخلية، منافذ، أحجام، وقت) — مختبرة آليًا في `tools/security-check.mjs`.
- الدقة المقاسة: [`accuracy.md`](accuracy.md).
