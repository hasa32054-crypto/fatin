# فطن و«كود المنصات» (هيئة الحكومة الرقمية)

> «كود المنصات» نظام تصميم موحّد أطلقته **هيئة الحكومة الرقمية** مع سدايا لتوحيد تجربة المنصات والتطبيقات الحكومية.
> فطن **ليس منصة حكومية** ولا يستخدم الهوية الحكومية البصرية — استخدامها محصور على الجهات. هذا المستند يوضح إن فطن مبني على نفس المبادئ، فلو تبنّته جهة يسهل تطبيق الكود الرسمي عليه.
> آخر تحديث: 9 أكتوبر 2026.

## الجاهزية

| مجال التجربة الرقمية | فطن اليوم | عند التبنّي من جهة |
|---|---|---|
| **العربية أولًا واتجاه RTL** | واجهة عربية أصلية RTL، و9 لغات إضافية مع LTR صحيح | — |
| **إمكانية الوصول** | WCAG 2.2 AA (تقرير ذاتي)، قارئ الشاشة، تكبير النص، تباين عالٍ، أوضاع للمكفوفين والصم وكبار السن | تدقيق مستقل |
| **التصميم المتجاوب** | من iPhone 12 mini (320px) إلى الحاسب، بدون تمرير أفقي (مختبر آليًا) | — |
| **مكوّنات موحّدة** | أزرار ولوحات وتنبيهات ببطاقات متسقة، ألوان كمتغيرات CSS | استبدال المتغيرات بألوان «كود المنصات» ومكوّناته — طبقة الألوان معزولة |
| **الهوية البصرية** | هوية فطن الخاصة (الدرع الكوفي) — **بدون شعارات حكومية** | تطبيق هوية الجهة وفق الكود |
| **الخطوط** | Alexandria وIBM Plex Sans Arabic، مستضافة ذاتيًا (بدون Google) | خط الكود الرسمي إن وُجد |
| **الأداء** | ملف واحد، بدون أطر عمل، يشتغل بدون إنترنت | — |
| **الخصوصية والموافقة** | موافقة صريحة قبل أي إرسال، سياسة خصوصية وشروط | سياسة الجهة |
| **الأمان** | CSP صارمة ببصمات، ترويسات أمان، 49 فحص آلي، مواءمة مع معيار الهيئة الوطنية للأمن السيبراني | اختبار اختراق معتمد |
| **التكامل** | API مفتوح (OpenAPI 3.1)، SDK، تطبيق مصغّر للتطبيقات الشاملة | الربط بالمنصة الوطنية الموحدة / توكلنا |
| **قياس الرضا** | استبيان SUS في الاختبار الميداني | مؤشرات الجهة |
