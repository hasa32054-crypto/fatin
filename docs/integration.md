# ربط فطن داخل التطبيقات الشاملة (توكلنا، أبشر، تطبيقات البنوك والاتصالات)

> **فطن جاهز تقنيًا يشتغل كتطبيق مصغّر** داخل أي تطبيق شامل. الإدراج الفعلي في توكلنا يتم **عن طريق جهة شريكة** في منصة توكلنا (الدليل الرسمي للمطورين: `partners.tawakkalna.sa/devdocs`) — ما يقدر فرد يرفعه بنفسه.
> فطن مشروع طالب مستقل، وليس تابعًا لأي جهة حكومية أو بنك.

## ليش فطن مناسب كتطبيق مصغّر؟

| المتطلب الشائع للتطبيقات المصغّرة | فطن |
|---|---|
| HTML/JS بدون خادم خاص | ✅ ملف واحد + خطوط ومكتبات محلية (`store/fatin-miniapp.zip`، ~0.9MB) |
| يشتغل بدون إنترنت | ✅ المحرك داخل الجهاز. الخادم اختياري (ذكاء اصطناعي، قارئ روابط، صوت) |
| أقل بيانات ممكنة | ✅ يقرأ **الاسم الأول والجنس فقط** للترحيب، ويبقون في الجهاز. **ما يقرأ** الهوية ولا الجوال ولا العنوان ولا الموقع |
| موافقة قبل أي إرسال | ✅ ما يطلع شي للخادم إلا بموافقة صريحة (نظام حماية البيانات الشخصية) |
| عربي أولًا + لغات الوافدين | ✅ 10 لغات |
| إمكانية الوصول | ✅ أوضاع: صوتي (مكفوفين)، اهتزاز ووميض (صم)، بسيط (كبار السن). تقرير WCAG في `wcag-report.md` |
| أمان | ✅ CSP صارمة ببصمات، بدون مكتبات خارجية، 49 فحص آلي (`tools/security-check.mjs`) |

## 1) الحزمة

```bash
python3 tools/build-miniapp.py     # ← store/fatin-miniapp.zip
```
- نفس التطبيق بوضع التضمين: بدون أزرار التثبيت، بدون Service Worker، وكل الروابط محلية.
- فيها `<script src="twkhelper.js">`: الجهة الشريكة تحط ملف توكلنا الرسمي بجانب `index.html` قبل الرفع (يُؤخذ من بوابة الشركاء).
- لو المنصة تشترط حد حجم، أكبر ملف هو `index.html` (~0.95MB مضغوطة ~0.5MB).

## 2) قراءة بيانات المستخدم من توكلنا (أقل حد)

فطن يستدعي (إذا كانت موجودة في `window.TWK`) فقط:
- `getUserFullName()` ← يأخذ **الاسم الأول** فقط للترحيب.
- `getUserGender()` ← لمخاطبة المستخدم صح (عربي: «انتبه/انتبهي»).

كل استدعاء محمي (لو فشل يكمل التطبيق عادي ويسأل المستخدم). **أسماء الدوال لازم تتأكد منها الجهة الشريكة من الدليل الرسمي** وقت الإدراج — الملف `app/index.html` (`FatinHost.fromTWK`) سطرين يتعدّلون.

## 3) الربط مع أي تطبيق مضيف (iframe أو WebView) — `postMessage`

افتح: `https://hasa32054-crypto.github.io/fatin/app/?embed=1&origin=https://YOUR-HOST.sa`

| من المضيف ← فطن | المعنى |
|---|---|
| `{type:"fatin:init", lang:"ur", mode:"visual", name:"محمد", gender:"m"}` | اللغة، وضع التنبيه (`general`/`visual`/`hearing`/`touch`/`simple`)، الاسم الأول |
| `{type:"fatin:check", text:"…"}` | افحص هذا النص (مثلًا: رسالة اختارها المستخدم من صندوق رسائل التطبيق) |
| `{type:"fatin:open", tab:"call"}` | افتح قسم (`scan`، `call`، `train`، `family`، `news`…) |

| من فطن ← المضيف | المعنى |
|---|---|
| `{source:"fatin", type:"fatin:ready", tabs:[…]}` | جاهز |
| `{source:"fatin", type:"fatin:result", verdict:"danger", score:95, signals:["otp","imp"]}` | نتيجة الفحص — **بدون نص الرسالة** |

**الأمان:** فطن يقبل الرسائل فقط من الأصل المذكور في `origin=` وبشرط يطابق الصفحة اللي فتحته، ويرسل النتائج لهذا الأصل فقط.

```html
<iframe id="fatin" src="https://hasa32054-crypto.github.io/fatin/app/?embed=1&origin=https://bank.example.sa"
        allow="microphone; camera" style="width:100%;height:100%;border:0"></iframe>
<script>
  const f = document.getElementById("fatin");
  addEventListener("message", e => {
    if (e.origin !== "https://hasa32054-crypto.github.io" || e.data?.source !== "fatin") return;
    if (e.data.type === "fatin:ready") f.contentWindow.postMessage({ type: "fatin:init", lang: "ar", mode: "simple" }, e.origin);
    if (e.data.type === "fatin:result" && e.data.verdict === "danger") showBankWarning();
  });
</script>
```

## 4) ربط بدون واجهة (خلف الكواليس)

- **SDK داخل التطبيق:** `sdk/fatin-engine.js` ← `Fatin.check(text)` بدون إنترنت.
- **API:** `/v1/check`، `/v1/link`، و`/v1/feed.stix` لمراكز الاستجابة. التفاصيل: [`api.md`](api.md).

## 5) أفكار ربط تخدم الجهات

| الجهة | الاستخدام |
|---|---|
| توكلنا / أبشر | خدمة «افحص رسالة» + مكالمات تدريبية للتوعية، بلغة المستخدم ووضع إعاقته |
| البنوك (عبر البنك المركزي) | فحص الرسالة قبل التحويل، وتدريب العملاء كبار السن |
| شركات الاتصالات (عبر هيئة الاتصالات) | بوت «أرسل الرسالة المشبوهة» يفحصها بـ`/v1/check` |
| المركز الوطني / مراكز الاستجابة | استيراد `/v1/feed.stix` كمؤشر إضافي |
| مساند / قوى | توعية العمالة الوافدة بلغاتهم قبل الوصول وبعده |
