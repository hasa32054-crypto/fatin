# نشر فطن في Google Play — الخطوات

كل شي جاهز في هذا المجلد: الإعدادات، صفحة المتجر بالعربي والإنجليزي، الصور، نموذج أمان البيانات، وخطة الاختبار المغلق.
**اللي عليك:** الحساب، وتوليد الحزمة، ورفعها. (حوالي ساعة، مرة وحدة)

| الملف | وش فيه |
|---|---|
| `listing.md` | الاسم والوصف (عربي/إنجليزي) + الإعدادات + أجوبة «أمان البيانات» — انسخ والصق |
| `screenshots/` | 7 لقطات جوال 1080×1920 |
| `feature-graphic.png` | صورة الميزة 1024×500 |
| `twa-manifest.json` | إعدادات الحزمة (إذا استخدمت Bubblewrap) |
| `assetlinks.json` | ملف ربط التطبيق بالموقع (تعبّي البصمة بعد الرفع) |
| `closed-test-plan.md` | الاختبار المغلق (12 مختبر × 14 يوم) = الدراسة الميدانية |

## 1) حساب المطوّر (أنت أو الوالد)
1. افتح `play.google.com/console` بحساب Google **شخصي** (مو حساب المدرسة).
2. نوع الحساب: **Personal**. الرسوم **25 دولار** مرة وحدة. لازم صاحب الحساب **18+** — إذا أقل، يفتحه الوالد باسمه.
3. يطلب توثيق هوية ورقم جوال — هذا داخل موقع Google فقط. **لا ترسل الهوية أو البطاقة لأي أحد ولا في المحادثة.**

## 2) توليد الحزمة (الأسهل: PWABuilder)
1. افتح `pwabuilder.com` واكتب: `https://hasa32054-crypto.github.io/fatin/app/`
2. **Package for stores ← Android ← Generate**. في الخيارات:
   - Package ID: `io.github.hasa32054crypto.fatin`
   - App name: `فطن · ضد الاحتيال` · Launcher name: `فطن`
   - Version: `1.0.0` · Version code: `1`
   - Signing key: **Create new** (احفظ الملف وكلمة المرور في مكان آمن عندك — لو ضاعت ما تقدر تحدّث التطبيق)
3. نزّل الملف المضغوط. فيه: `app-release-bundle.aab` و`assetlinks.json` ومفتاح التوقيع.

> بديل للمحترفين: `npm i -g @bubblewrap/cli` ثم `bubblewrap init --manifest=https://hasa32054-crypto.github.io/fatin/app/manifest.webmanifest` واستخدم القيم في `twa-manifest.json`، ثم `bubblewrap build`.

## 3) ربط التطبيق بالموقع (عشان يفتح بدون شريط المتصفح)
ملف `assetlinks.json` لازم يكون في **جذر** النطاق: `https://hasa32054-crypto.github.io/.well-known/assetlinks.json`
1. في GitHub أنشئ مستودع جديد عام باسم **`hasa32054-crypto.github.io`** بالضبط.
2. ارفع فيه: ملف فاضي اسمه `.nojekyll`، ومجلد `.well-known` فيه `assetlinks.json`.
3. البصمة: Play Console ← تطبيقك ← **Setup ← App signing** ← انسخ **SHA-256** من «App signing key certificate» وحطها مكان النص في الملف (تقدر تحط بصمتين: مفتاح Google ومفتاح الرفع).
4. تأكد: افتح الرابط في المتصفح لازم يطلع الملف.
5. ارسل لي البصمة (هي عامة وآمنة، مو سر) وأنا أحدّث الملف هنا.

## 4) الرفع والاختبار المغلق
1. Play Console ← **Create app** ← الاسم «فطن · ضد الاحتيال»، اللغة العربية، App، مجاني.
2. عبّي **App content**: سياسة الخصوصية (الرابط في `listing.md`)، الإعلانات: لا، الجمهور: 18+، **Data safety** من الجدول في `listing.md`، التطبيقات الحكومية/المالية: لا.
3. **Main store listing**: انسخ من `listing.md` وارفع الصور.
4. **Testing ← Closed testing ← Create track** ← ارفع `.aab` ← أضف إيميلات المختبرين (16) ← أرسل للمراجعة.
5. شارك رابط الاختبار مع المشاركين، وامشِ على `closed-test-plan.md`.
6. بعد 14 يوم: **Apply for production**.

## ملاحظات مهمة
- فطن في المتجر **لا يقول إنه تابع لأي جهة حكومية أو بنك** — Google ترفض أي تطبيق يوحي بانتحال جهة.
- أي تحديث للموقع يوصل للتطبيق تلقائيًا (لأنه نفس الموقع)، ما تحتاج ترفع نسخة جديدة إلا لو تغيّرت الأيقونة أو الاسم.
- iPhone (App Store): 99 دولار سنويًا ويحتاج جهاز Mac. خلّه بعد نجاح أندرويد — الحين مستخدمو iPhone يضيفونه للشاشة الرئيسية من Safari.
